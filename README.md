Student Grade Calculator

A simple Java-based Student Grade Calculator developed as part of my CodSoft Java Development Internship.

Features

* Takes marks as input
* Calculates total marks
* Calculates average percentage
* Assigns grade based on percentage
* Displays the final result clearly

Technologies Used

* Java
* VS Code
* Git
* GitHub

How to Run

1. Clone or download the repository.
2. Open the project in VS Code.
3. Compile the Java file.
4. Run the program.
5. Enter the required marks when prompted.

Project Purpose

This project was created to practice Java programming, input handling, calculations, conditional statements, and basic Git/GitHub workflow.

Internship
